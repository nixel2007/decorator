# decorator

[![Тестирование](https://github.com/nixel2007/decorator/actions/workflows/testing.yml/badge.svg?branch=master)](https://github.com/nixel2007/decorator/actions/workflows/testing.yml)
[![Статус порога качества](https://sonar.openbsl.ru/api/project_badges/measure?project=decorator&metric=alert_status)](https://sonar.openbsl.ru/dashboard?id=decorator)


Библиотека для создания оберток (декораторов) над классами.

Декоратор повторяет публичный интерфейс класса (экспортные методы и поля),
делегируя вызов вложенному реальному объекту.

Возможности:

* создание декоратора с идентичным интерфейсом;
* синхронизация значений полей декоратора и реального объекта;
* добавление методов, импортов, полей, шагов инициализации в runtime;
* добавление перехватчиков ("перед", "после") вызова метода;
* объединение слоёв: декоратор над декоратором строится сразу над реальным объектом.

## Пример использования:

```bsl
#Использовать decorator

КакойТоКласс = Новый КакойТоКласс();
КакойТоКласс.Поле = 123;

Поле = Новый Поле("НовоеПоле")
	.Публичное()
	.ЗначениеПоУмолчанию("ЗначениеПоУмолчанию");

Метод = Новый Метод("ДобавленнаяФункция")
	.Публичный()
	.ТелоМетода("Возврат Поле + 1;");

Перехватчик = Новый Перехватчик("ДобавленнаяФункция")
	.ТипПерехватчика(ТипыПерехватчиковМетода.Перед)
	.Тело("Сообщить(""Привет, мир!"")");

Декоратор = Новый ПостроительДекоратора(КакойТоКласс)
    .Импорт(Новый Импорт("fs"))
    .Поле(Поле)
    .Метод(Метод)
    .Перехватчик(Перехватчик)
    .Построить();

Ожидаем.Что(Декоратор.Поле).Равно(123);
Ожидаем.Что(Декоратор.РоднаяФункцияВозвращающаяИстина()).ЭтоИстина();
Ожидаем.Что(Декоратор.ДобавленнаяФункция()).Равно(124);
```

### Объединение слоёв

Декоратор над декоратором не вкладывается: построитель добирается до реального
объекта и переносит внутрь изменения развёрнутых слоёв. Цепочка вызовов остаётся
одноуровневой, а поля, методы, перехватчики, импорты и шаги инициализации всех
слоёв оказываются в одном модуле.

```bsl
КакойТоКласс = Новый КакойТоКласс();
КакойТоКласс.Поле = 123;

Внутренний = Новый ПостроительДекоратора(КакойТоКласс)
    .Поле(Новый Поле("СчётчикВызовов").Публичное().ЗначениеПоУмолчанию(0))
    .Перехватчик(Новый Перехватчик("РоднаяФункцияВозвращающаяИстина")
        .ТипПерехватчика(ТипыПерехватчиковМетода.Перед)
        .Тело("СчётчикВызовов = СчётчикВызовов + 1;"))
    .Построить();

Внешний = Новый ПостроительДекоратора(Внутренний)
    .Метод(Новый Метод("Удвоить").Публичный().ТелоМетода("Возврат Поле * 2;"))
    .Построить();

Внешний.РоднаяФункцияВозвращающаяИстина();

// Поле и перехватчик внутреннего слоя оказались во внешнем декораторе,
// а вызов пошёл сразу в КакойТоКласс, минуя Внутренний
Ожидаем.Что(Внешний.СчётчикВызовов).Равно(1);
Ожидаем.Что(Внешний.Удвоить()).Равно(246);
```

Правила слияния:

* поля и методы слоёв добавляются после полей и методов реального объекта;
* импорты объединяются, повторы отбрасываются;
* шаги инициализации выполняются от внутреннего слоя к внешнему;
* перехватчики "до" (`Перед`, `ПередСинхронизациейПолей`) отрабатывают от внешнего
  слоя к внутреннему, "после" (`После`, `ПослеВызоваИсключения`) — наоборот;
* одинаковое имя поля или метода в двух слоях, либо совпадение с именем у реального
  объекта или со служебным полем декоратора — исключение при построении.

Развёрнутый декоратор в цепочке вызовов больше не участвует: его состояние
копируется в построенный декоратор один раз, дальше объекты живут независимо.

Внутри перенесённых тел `Декоратор_ИсходныйОбъект` всегда указывает на реальный
объект. Обращение вида `Декоратор_ИсходныйОбъект.<метод соседнего слоя>` до
объединения работало, а после — сломалось бы, поэтому построитель ловит его и
выбрасывает исключение с подсказкой использовать `ЭтотОбъект.<метод>`. Комментарии
и строковые литералы при этом не просматриваются, но и вызов через промежуточную
переменную проверка не увидит.

#### Как отключить

`ОбъединятьСлои(Ложь)` означает и "сам не разворачиваю то, что мне передали",
и "не даю развернуть себя": построенный декоратор не оставляет рецепта, поэтому
следующий слой вложит его, как в версии 2.x.

```bsl
Внутренний = Новый ПостроительДекоратора(КакойТоКласс)
    .ОбъединятьСлои(Ложь)
    .Построить();

Внешний = Новый ПостроительДекоратора(Внутренний).Построить();
// Внешний -> Внутренний -> КакойТоКласс
```

### Отладка добавляемых методов

Для того, что бы работал отладчик и заходил в добавленные методы нужно: Либо установить любое значение переменной окружения с именем ```OSCRIPT_DECORATOR_DEBUG```. Либо вызвать у построителя метод ```Отладка()```

```bsl
Декоратор = Новый ПостроительДекоратора(КакойТоКласс)
    .Импорт(Новый Импорт("fs"))
    .Поле(Поле)
    .Метод(Метод)
    .Перехватчик(Перехватчик)
    .Отладка()
    .Построить();
```

#### ОбъединятьСлои

```bsl
// Управляет объединением слоёв вложенных декораторов.
//
// При включённом объединении декоратор над декоратором строится сразу над
// исходным объектом, а изменения развёрнутых слоёв переносятся внутрь.
// При выключенном декоратор вкладывается, и построенный объект не оставляет
// рецепта, поэтому и следующий слой развернуть его не сможет.
//
// Параметры:
//   Включено - Булево - Объединять слои
//
//  Возвращаемое значение:
//   ПостроительДекоратора - Ссылка на текущий инстанс ПостроительДекоратора
//
Функция ОбъединятьСлои(Включено = Истина) Экспорт
```

#### ДопуститьОтсутствиеИнстанса

```bsl
// Разрешает построение декоратора без инстанса исходного объекта.
// Действует в режиме создания из типа: если конструктор типа выбрасывает исключение,
// построение не прерывается, а декоратор строится без инстанса (Неопределено).
// Интерфейс типа при этом полностью сохраняется, но делегирование вызовов
// в исходный объект и синхронизация полей недоступны.
//
// Параметры:
//   Допустить - Булево - Признак допустимости отсутствия инстанса
//
//  Возвращаемое значение:
//   ПостроительДекоратора - Ссылка на текущий инстанс ПостроительДекоратора
//
Функция ДопуститьОтсутствиеИнстанса(Допустить = Истина) Экспорт
```

Пример — декоратор над типом, который нельзя создать через конструктор (например, `HTTPОтвет`):

```bsl
Перехватчик = Новый Перехватчик("ПолучитьТелоКакСтроку")
	.ТипПерехватчика(ТипыПерехватчиковМетода.Перед)
	.Тело("Возврат ""Переопределенный ответ"";");

Декоратор = Новый ПостроительДекоратора(Тип("HTTPОтвет"))
	.ДопуститьОтсутствиеИнстанса()
	.Перехватчик(Перехватчик)
	.Построить();
```

## Переход с 2.x на 3.0

Всё, кроме первого пункта, откатывается вызовом `ОбъединятьСлои(Ложь)` у построителя.

1. Удалён класс `КонструкторДекоратора` и весь API версии 1. Используйте `ПостроительДекоратора`.
2. `Декоратор_ИсходныйОбъект` теперь всегда содержит реальный объект, а не соседний декоратор.
3. Переданный в конструктор декоратор в цепочке вызовов больше не участвует: его
   состояние копируется один раз при построении, дальше объекты живут независимо.
4. Блок `Попытка` охватывает только вызов метода реального объекта. Раньше `Попытка`
   внешнего декоратора охватывала всю обёртку внутреннего, поэтому исключение из
   перехватчика внутреннего слоя запускало `ПослеВызоваИсключения` внешнего. Теперь нет.
5. Конфликт имён полей и методов между слоями, с реальным объектом или со служебными
   полями декоратора — исключение при построении вместо ошибки компиляции сценария.
6. Обращение `Декоратор_ИсходныйОбъект.<метод соседнего слоя>` в теле метода,
   перехватчика или шага инициализации — исключение при построении.
